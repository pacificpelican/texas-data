# Texas Regional Vault

A lightweight PHP prototype for a Texas regional file portal built with:

- a clickable Texas map split into five regions
- region-specific file lists
- user login via email or a Google-style email flow
- file uploads saved locally in the app's storage folder

## Run locally

From the project directory:

```bash
php -S 127.0.0.1:8000
```

Then open:

```text
http://127.0.0.1:8000
```
